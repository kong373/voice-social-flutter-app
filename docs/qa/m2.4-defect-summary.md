## 13. 关闭规则

缺陷只有同时满足以下条件才能标记 CLOSED：

1. 修复前复现步骤、实际/预期、严重度和证据完整；
2. 修复代码绑定明确受测 commit；
3. 有对应自动化回归，且未降低断言或扩大视口；
4. 定向测试和全量 flutter test 通过；
5. 重建 QA APK并记录 SHA；
6. AVD-A 复测通过；所有 P1 同时在 AVD-B 通过；
7. 截图、视频和 Logcat 已关联 defects.csv；
8. 关联模块和 FLOW 核心回归通过；
9. 无新 Crash、ANR、overflow、错误路由或权限越权。

首轮 run 已返回 AVD-A 证据，但结论为 FAIL，AVD-B 又是 `BLOCKED_RUNNER_HANG`。因此本摘要中的 M24-EMU-001～026 均不得标记 CLOSED；本地候选、静态检查、AVD-A 局部 PASS、截图数量 PASS 或 app hard Logcat count 0 都不能替代新的双 AVD 关闭证据。
