## 2. 结论词与边界

最终结果只能使用 ANDROID_EMULATOR_PASS、ANDROID_EMULATOR_FAIL 或 BLOCKED。run 31888563720 的首轮历史结论为 FAIL；最新 v3 run 31898248951 的 AVD-A 仍为严格 FAIL，AVD-B 再次为 `BLOCKED_RUNNER_HANG`，因此最新总判定仍是 `ANDROID_EMULATOR_FAIL`，当前执行状态为 `RETEST_PENDING`。任何局部截图、release gate、静态门禁或构建成功都不得改写成整体 PASS。

必须始终单列：

- REAL_DEVICE_PENDING：尚未使用 Android 实体设备验证。
- IOS_PENDING：尚未使用 iOS Simulator 或 iPhone 验证。
- VENDOR_BLOCKED：RTC、腾讯 IM、微信支付、支付宝、Apple IAP、推送、对象存储和部分原生权限适配器尚未接入。
- MISSING_IMPLEMENTATION：Manifest 中有 Page ID，但没有真实页面或可执行逻辑。
- NOT_APPLICABLE：确实不适用，并必须写明理由。

Mock 业务成功只能描述为 Mock/离线业务通过，不能描述为真实语音、真实 IM、真实支付、真实推送或真实后端联调通过。

## 4. 构建与 APK 基线

### 4.1 参考 APK 黑盒轮次

1. 使用已核验哈希的参考 APK，不修改包内容。
2. 由 apkanalyzer 或 aapt 自动读取 package name、minSdk、targetSdk、versionName、versionCode 和 ABI；不得猜测。
3. 清空 Logcat，记录旧安装版本。
4. 先 adb install -r；签名冲突时记录证据，再卸载旧包并重新安装。
5. 验证能安装、能启动、非白屏、无立即 Crash/ANR、断网不无限 loading。
6. 这一轮只形成 APK 黑盒基线，不等于 69 页覆盖。

### 4.2 QA Debug APK

云 CI 使用实际 commit 构建：

~~~bash
flutter build apk --debug \
  --dart-define=BACKEND_MODE=mock \
  --dart-define=ENABLE_QA_CONSOLE=true \
  --dart-define=GIT_COMMIT=<tested-sha> \
  --dart-define=PACKAGE_VERSION=0.5.0+5
~~~

产物命名为 voice-social-app-m2.4-qa-debug.apk，计算新 SHA-256 并写入 apk_sha256.txt。不得用 QA APK 的结果冒充参考 APK 黑盒结果。

3. flutter test --coverage --concurrency=1 --timeout=60s
4. 验证 Manifest 为精确 69 ID、无重复、无非法新增，QA catalog 与 Manifest 一一对应。
5. 验证 Release/非开关 Debug 中 QA 控制台不可见、不可路由。

### Phase 1：参考 APK 黑盒

按第 4.1 节完成安装、启动、离线冷启动和初始 Logcat 检查。结果保持独立记录。

### Phase 2：QA APK 与 69 页目录

- 69 Page ID 目录、搜索和 AC/DS/US/RM/MS/CM/SC 筛选；

## 9. 安全、产品硬约束与供应商边界

必须验证：

- 根导航固定为首页/发现/消息/我的；DS-001 是首页，DS-004 是发现动态流。
- 有效房间入口直接进入 RM-004；RM-003 只处理校验和失效恢复。
- RM-004 固定 8 麦，无第 9 个房主麦；麦位状态完整。
- 公屏不伪造进房前或断线期间历史；重连显示指定历史限制提示。
- 房内礼物保持 Bottom Sheet 和房间上下文；离房真实退出；房主离开与关闭分离。
- Android 支付只显示微信支付和支付宝；支付结果以服务端状态为准。
- 青少年模式只阻止创建新充值订单。
- 高风险操作均二次确认。
- 可见 UI、有效路由、推荐位、Mock 数据、礼物和活动目录不得出现红包、red packet、KTV、点歌、演唱、合唱、盲盒、blind box、魔法球、magic ball、团子、dango、情书、love letter、随机遇见、随机匹配、附近的人、附近房间、扫码、易票联。

内部 deny-list、后端过滤器和测试断言中的关键词可作为审计实现存在，但必须证明不会渲染到可见 UI。否定式宣传文案也不豁免“可见命中为 0”的标准。

供应商能力只能验证诚实边界和 fail closed：RTC、腾讯 IM、微信支付、支付宝、Apple IAP、推送、对象存储和原生权限不得伪造成功。

## 10. 日志、稳定性和性能

全程保存 threadtime Logcat，并扫描：FATAL EXCEPTION、ANR、RenderFlex overflow、setState() called after dispose、deactivated widget、Unhandled Exception、Null check、Bad state、LateInitializationError、PlatformException、MissingPluginException、SocketException、TimeoutException。

模拟器门槛：

- Crash、ANR、持续白屏为 0；
- 普通点击 500 ms 内反馈，Mock 操作 3 秒内完成；
- 冷启动建议不超过 5 秒，热启动不超过 2.5 秒；超出记 P2 并注明宿主；
