# 注册预设头像组件

依据用户填写的 R01：上传头像或主动选择预设，需要设计几款默认头像。
本批由同一 ChatGPT 协作任务交付后在主机审查，采用六款原生 Canvas 插画：
月兔、暖阳、云朵、星狐、小鲸、叶熊；ID 与 Backend RegistrationProfilePolicy 相同。
没有网络图片、Emoji、随机默认值、第三方素材或新运行时依赖。

Picker 为受控组件：null/未知 ID 不选中任何一款，点击只向上报告确切 ID；
父级更新 selectedId 才显示选中。禁用状态不回调，单一语义节点携带标签与选择状态；
文字 1.0/1.3、窄屏、减少动态效果均有测试。32px 与64px作品和选择环经图片检查。

验证：Flutter 3.44.7 / Dart 3.12.2；18/18测试，5文件analyze零问题，format/diff-check。
新头像截图只更新自身基线，旧golden和字体完全未改。新增4596字节、同上游固定SHA的
四字形测试字体，来源/许可证在test/fonts，运行时不打包这个测试补充字体。

首次13个widget测试失败为重复申请SemanticsHandle的夹具泄漏，已保留失败记录并修正
为断言testWidgets自带semanticsEnabled，不删除任何语义断言。
首次新截图出现缺字，已补同源固定字形后重新截图，主审确认六个名称可读。

本批只是可复用头像和选择器，尚未接入注册上传/提交/正式头像读取，不声称注册闭环完成。
