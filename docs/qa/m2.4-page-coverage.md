## 10. 页面证据命名与完成规则

页面截图使用 {PageID}-{state}-{AVD}-{viewport}-{fontScale}.png，例如 RM-004-normal-AVD-A-390x844-1.0x.png。每个真实实现 Page ID 至少保留 1 张 1.0× normal 和 1 张 1.3× normal，最低 138 张。

单页只有在以下条件全部满足后才能从 RETEST_PENDING 改为 PASS：

1. 普通用户入口和 QA 入口都打开同一真实业务实现；
2. AVD-A 可打开，关键页面 AVD-B 可打开；
3. 全部可见按钮实际点击并验证结果；
4. 必要角色和状态已覆盖；
5. 360×800、390×844、1.3× 无 overflow；
6. 输入页键盘可达，长列表可滚动到底；
7. 无 Crash、ANR 或未解释异常；
8. 截图、视频、Logcat 和缺陷字段已填写；
9. 供应商能力诚实标记 VENDOR_BLOCKED，不伪造成功。
