# 唯一个人中心与关联页面收口

## 范围

以用户明确选定的第二张个人中心为“我的”唯一根内容，Android/iOS共用实现。`VideoRuntimeAccountPage`只负责接入根页和环境专属入口，不再维护第二套个人中心和重复资料请求。保留可独立推入的`PersonalCenterPage`返回能力，但App正常入口不再多push一层。

| Before | After | Why |
| --- | --- | --- |
| 我的→头像/设置→第二套个人中心 | 我的直接显示完整个人中心；头像/资料直达编辑，设置直达账号安全 | 删除重复层级，保留真实返回路径与底栏 |
| 根页缺失图2装扮陈列；开发诊断占据首屏 | 装扮陈列、钱包/装扮/资料、房间、8工具统一；诊断只在调试开发环境底部 | 保持用户选定的视觉结构与正式环境边界 |
| 两张“最近进房”实际都打开收藏 | 一个收藏入口；仅有实际roomId时显示正在收听 | 不把同一收藏入口和装饰头像伪装为两条历史记录 |
| 小字体、32dp装扮CTA、硬接缝、固定四列 | 44dp CTA、圆角衔接、提高辅助文字可读性、自适应工具列数与底栏留白 | 小屏和1.3字号可达，不引入无意义动效 |
| 普通用户入口也写现金收益 | 我的只写钱包，钱包副标题按incomeEligible显示 | 不改变收益/提现能力门控、账本与资金规则 |

## 保留的行为

- ProfileDisplayReadFence、账号代次/请求代次保护；切回“我的”重新读资料，资料/关系/装扮返回刷新。
- 当前会话账号传递；退出仍由AppGate执行，根页不假造二级返回。
- 通知、隐私/黑名单、帮助、平台工作人员服务端权限入口。
- 资料加载失败仍可退出；平台权限入口不依赖社交资料成功。
- 不修改Backend、厂商、付款、收益与提现规则，不迁移数据。
