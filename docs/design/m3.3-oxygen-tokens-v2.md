# M3.3 Oxygen Tokens v2

This token set names the two visual systems that govern the 69-page scope:

- `SocialSky` for the light social shell
- `RoomImmersive` for the dark room shell

The values below are aligned to the existing Flutter theme in
`lib/core/design_system/app_theme.dart` and `lib/core/design_system/runtime_surfaces.dart`.

## Shared Transparency And Shadow

- Light surfaces use translucent borders in the `6-14%` range.
- Room surfaces use bloom-like shadows instead of hard gray elevation.
- Room cards and sheets should stay translucent enough to keep the cosmic background visible.
- The light shell should stay frosted rather than flat white.

## Motion

| Motion use | Recommendation |
| --- | --- |
| page entrance | `180-240ms`, ease-out |
| bottom sheet | `220-280ms`, ease-out |
| room overlay / stage transition | `240-320ms`, ease-out |
| tab or chip state change | `120-180ms`, linear or ease-out |
| loading to success | short fade, no bounce |

- Keep motion restrained.
- Do not add heavy spring motion or bouncy transitions.
- Respect reduced-motion behavior where the platform asks for it.

## Surface Rules

- `SocialSky` pages should use the pale sky background, white cards, and purple primary actions.
- `RoomImmersive` pages should use the deep indigo background, floating translucent layers, and cyan/pink accents.
- Commerce sheets may borrow either shell, but the hierarchy should stay compact and sheet-like.
- No page may introduce membership, VIP rights, gift backpack, or gift inventory visuals.
