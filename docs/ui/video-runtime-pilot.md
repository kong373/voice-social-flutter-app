# M3.3 Runtime-video UI pilot

This pilot replaces the invalid all-dark card treatment with the interaction language observed in the user-provided runtime recording while preserving the approved 69-page business scope.

## Pilot surfaces

1. Light, mixed-density social lobby home.
2. Dark immersive fixed-eight-seat voice room.
3. In-room keyboard state that preserves room context.
4. In-room gift and more-tool bottom sheets.
5. Room minimization and cross-tab restore pill.
6. Fixed root navigation: 首页 / 发现 / 消息 / 我的.

## Hard boundaries

- No competitor brand, logo, illustration, gift asset or event material is copied.
- Retired features remain absent.
- RTC, IM, SMS, payment, push and object-storage providers remain fail-closed.
- No provider call is made by this UI pilot.
- The pilot must pass format, analyze, unit/widget tests and both exact Android viewports before visual review.

## Visual acceptance

The pilot is not accepted by static design alone. Required evidence is the final Flutter render at 390×844 and 360×800, including home, room, keyboard-open room, gift sheet, more-tools sheet, minimized room pill, message and account surfaces.
