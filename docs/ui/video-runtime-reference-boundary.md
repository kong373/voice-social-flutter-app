# Clean-room reference boundary

The user-provided recording is used to understand hierarchy, interaction timing, scene transitions and state behavior only.

The implementation may reproduce:

- light social lobby versus dark immersive room scene separation;
- mixed-size content composition;
- in-room contextual bottom sheets;
- fixed eight-seat room state presentation;
- keyboard, gift, tool, minimization and restore interaction patterns.

The implementation must not copy:

- the competitor name, logo or trademarked identity;
- proprietary illustrations, portraits, room backgrounds, gifts or activity art;
- source strings, campaign materials or retired functions;
- byte-identical icons or complete branded screen compositions.
