# M2.3 — Discovery and community business core without vendor SDKs

## Scope

This checkpoint implements the product business that can run without Agora/Zego RTC, Tencent IM, payment invocation, object storage, or native permission adapters.

### Discovery

- DS-004 dynamic feed with category filters, refresh, pagination, empty/error states, post-specific likes, and direct routes to details.
- DS-005 dynamic detail and comments with reply context, retained input, authoritative refresh, and owner-only deletion.
- DS-006 text-first publishing with content/category/topic/location validation. Image publishing fails closed until object storage is connected.
- DS-007 charm, wealth, contribution, and room rankings. User targets open public profiles; valid room targets go through RM-003 validation and then RM-004.

### Community

- SC-001 guild home, search, current membership, recommended guilds, sign-in, and direct valid guild-room entry.
- SC-002 membership application, member list, application review, member mute/unmute, and removal by exact record ID.
- SC-003 invite/channel attribution. Live mode is explicitly unavailable because no confirmed end-user attribution endpoint exists.
- SC-004 CP relation list, eligibility check, outgoing request, and incoming accept/reject. No random matching is added.
- SC-005 guardian tiers, fan-team relationship, and fan tasks.
- SC-006 daily check-in, task progress, and server-authoritative reward claiming.
- SC-007 theme activity catalog. Live mode is explicitly unavailable until a confirmed generic activity endpoint exists.

## Deliberate boundaries

- No IM message is fabricated for CP or guild actions; HTTP state is the authority until Tencent IM is connected.
- No client-side image upload placeholder is submitted as evidence.
- No activity is generated in Live mode without a generic server catalog.
- No invite/channel attribution is generated or modified on the client.
- No retired capability is exposed: red packet, KTV/song/singing/chorus, blind box, magic ball, dango, or love letter.
- No random match, nearby people, scan, or other unconfirmed entry is added.
