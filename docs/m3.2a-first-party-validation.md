# M3.2A first-party validation

This branch contains only vendor-independent application behavior:

- OAuth public-client authentication and rotating sessions;
- current-user, discovery, search, room snapshot, wallet, and order reads;
- fail-closed boundaries for SMS delivery, RTC, IM, payment, push, and object storage;
- no provider secret in the distributed mobile application.

The branch remains Draft and unmerged until Flutter CI, the live development backend contract, and the two exact-viewport Android emulator runs pass on the same candidate SHA.
